# Security Policy

## Scope

This repository is a public research-stage reference implementation. It is not an approved production, classified, CUI, or operational system. Do not submit secrets, credentials, personal data, classified information, CUI, export-controlled material, or sensitive operational details in issues or pull requests.

## Reporting a vulnerability

Do not publish exploit details or sensitive evidence in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If private reporting is unavailable, contact the repository owner through a verified private channel and provide only the minimum information needed to establish contact. Do not assume an unverified email address.

## Response expectations

Reports will be triaged on a best-effort basis. No response-time SLA, coordinated disclosure deadline, bug-bounty program, or security certification is currently offered.

## Supported versions

No production-supported release has been declared. The default branch is a research codebase; consumers must independently review and validate it before any use.
